# Проект: флеш-карточки

## Что это
PWA-приложение с карточками для учёбы. Основное устройство: iPhone (Safari, "На экран Домой"). Я учусь программированию, поэтому объясняй простыми словами.

## Стек
Чистые HTML, CSS и JavaScript, без тяжёлых фреймворков. Данные хранятся в браузере (localStorage или IndexedDB), офлайн-режим через service worker.

## Как работаем
- Требования лежат в IDEAS.md, это главный источник.
- Сначала analyst предлагает план, я утверждаю.
- Потом coder делает по одному шагу, tester проверяет.
- Уроки к карточкам пишет tutor.
- После успешного шага делаем git commit (когда Git установлен).
- Без моего согласия не добавляем зависимости и не меняем стек.
- Кнопки и текст удобны для телефона: крупные, без наведения мышью.
- Если я прошу, объясняй написанный код строка за строкой.
